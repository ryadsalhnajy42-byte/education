## 📌 نبذة عن المشروع
مشروع تخرج لنيل شهادة البكالوريوس في **تقنية المعلومات** من **جامعة اليمن والخليج للعلوم والتكنولوجيا (2026م)**.

يهدف المشروع إلى تقديم حل تقني متكامل ومبتكر لمواجهة التحديات المادية واللوجستية والإدارية التي تواجه **المؤسسة الوطنية لمكافحة السرطان في اليمن** جراء الظروف الراهنة. يربط النظام بين المؤسسة، والمتبرعين، والأطفال المرضى، لمساندتهم مادياً ومعنوياً وتعليمياً.

## 🎯 الأهداف الرئيسية للمشروع
1. **تعزيز التواصل المباشر:** تيسير التواصل بين المؤسسة والأطفال المصابين للوقوف على احتياجاتهم ودعمهم.
2. **سوق الأمل (متجر إلكتروني للتبرع):** إتاحة الفرصة للمتبرعين لعرض وبيع المنتجات/المقتنيات المستعملة والجديدة وتوجيه ريعها لدعم المؤسسة.
3. **مجتمع الأمل (دعم نفسي واجتماعي):** بيئة تفاعلية تسمح للأطفال بنشر أنشطتهم وتجاربهم وإلهام بعضهم، وتمكين المتبرعين من دعمهم.
4. **مدرسة الأمل (تعويض الفاقد التعليمي):** توفير منصة للأطفال لطلب دروس تعليمية مصورة يقوم المتطوعون والمتبرعون برفعها لمساعدتهم في استكمال تعليمهم أثناء فترة العلاج.
5. **إدارة لوجستية وإدارية متمكنة:** أدوات رقمية تمكّن إدارة المؤسسة والمناديب من متابعة التبرعات، المنتجات، والطلبات، والفعاليات، وعرض التقارير.

## 🛠️ البنية التقنية (Tech Stack)

### **الواجهات الأمامية (Frontend):**
* **تطبيق الويب:** React.js / Vue.js
* **تطبيقات الجوال:** Flutter (Android & iOS)

### **الخلفية وقواعد البيانات (Backend & Database):**
* **خادم التطبيقات:** Node.js (Express.js) / Python (Django)
* **قاعدة البيانات:** PostgreSQL
* **الربط البرمجي:** RESTful APIs

### **الخدمات السحابية والأمان (Cloud & Security):**
* **تخزين الوسائط:** Cloudinary / AWS S3 / Digital Ocean (لمعالجة وتخزين الفيديوهات)
* **المصادقة والأذونات:** Laravel Sanctum & Spatie (إدارة الصلاحيات والأدوار)
* **الحماية ونقل المحتوى:** Cloudflare

## 👥 الفاعلون في النظام (System Actors)
* **👶 الطفل (Child):** تصفح مدرسة الأمل، طلب دروس، نشر منشورات وتجارب، والتواصل مع المؤسسة.
* **🤝 المتبرع (Donor):** شراء/عرض منتجات للبيع في سوق الأمل، رفع دروس تعليمية للأطفال، والتفاعل مع منشورات مجتمع الأمل.
* **🚚 المندوب (Delivery Delegate):** استلام المنتجات المبرع بها وتوصيلها للمشترين وتحديث حالة الطلبات.
* **👨‍💼 الموظف / المسؤول (Admin / Staff):** تسعير المنتجات، إجازة المنشورات والدروس، إدارات حسابات الأطفال والمناديب، وإرسال الرسائل الفردية والجماعية.
